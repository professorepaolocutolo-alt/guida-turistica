#  Guide Turistiche Campania & Isola di Ventotene

> *"La bellezza salverà il mondo."* — Fëdor Dostoevskij

Sito web di presentazione dedicato alle visite guidate in Campania (**Napoli**, **Pompei**, **Ercolano**, **Campi Flegrei**) e sull'**Isola di Ventotene**.

## Caratteristiche
* **Multilingua:** Disponibile in Italiano, Inglese e Francese con cambio lingua istantaneo.
* **Proposte su misura:** Itinerari dedicati a **Scuole**, **Turisti** e **Convegnisti**.
* **Design responsive:** Ottimizzato per smartphone, tablet e computer.

## Tecnologie utilizzate
* HTML5, CSS3 e JavaScript puro (file singolo `index.html`).
